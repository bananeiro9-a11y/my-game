Особенности игры
Уровни из JSON: Карта каждого уровня подгружается из внешних файлов конфигурации (легко добавлять новые уровни).

Система жизней и смертей: При контакте с лавой персонаж превращается в призрака и улетает вверх, после чего теряется жизнь.

Интерактивные элементы:

Золотые монетки для сбора и подсчета очков.

Опасная лава.

Дверь-переход на следующий уровень.

Главное меню: Удобное меню с кнопками старта и выхода.

Звуковое сопровождение: Звуки прыжков, сбора монеток и проигрыша.

🚗 Секретная фича: В коде затаился класс Car (потому что почему бы и нет).

🎮 Управление
Стрелки «Влево» / «Вправо» — движение персонажа.

Пробел (Space) — прыжок.

ЛКМ (Левая кнопка мыши) — взаимодействие с кнопками в меню.

⚙️ Установка и запуск
Убедись, что у тебя установлен Python.

Установи библиотеку Pygame, если она еще не установлена:

Bash
pip install pygame
Скачай проект и запусти главный файл:

Bash
python main.py
